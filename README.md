# Portfolio Project

## Overview

Welcome to my portfolio project! This portfolio is built using React.js and Tailwind CSS to showcase my skills and projects. It leverages several React hooks such as `useState`, `useRef`, and `useEffect` to manage state, references, and side effects effectively.

## Tech Stack

- **React.js**: A JavaScript library for building user interfaces.
- **Tailwind CSS**: A utility-first CSS framework for rapid UI development.

## React Hooks Used

- **useState**: For managing state in functional components.
- **useRef**: For accessing and interacting with DOM elements.
- **useEffect**: For handling side effects in functional components.

## Getting Started

To run this project on your local device, follow these steps:

1. Clone the GitHub repository:

    ```sh
    git clone <repository-url>
    ```

2. Navigate to the project directory:

    ```sh
    cd dev-port
    ```

3. Install the necessary dependencies:

    ```sh
    npm install
    ```

4. Start the development server:

    ```sh
    npm run dev
    ```
